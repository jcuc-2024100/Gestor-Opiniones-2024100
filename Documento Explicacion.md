# README

- Este proyecto es un microservicio  para hacer la parte de seguridad de un sistema como un gestor de opiniones.

- el proyecto nos permite registrar usuarios, iniciar sesión, verificar su correo electrónico y recuperar su contraseña en caso de que la olviden. También maneja los roles de los usuarios, por ejemplo, si son administradores o usuarios normales.

- En pocas palabras, este proyecto se encarga de controlar quién puede entrar al sistema y asegurar que la información de los usuarios esté protegida.

- Este proyecto es un microservicio que hace o se encarga de la seguridad y el acceso de usuarios dentro del sistema, la funcion principal de el gestor de opiniones es poder ver o controlar que personas o usuarios entran a el sistema y que la informacion de los usuarios este protegida.


- La aplicacion nos permite que los usuarios se puedan registrar y pueden iniciar sesion utilizar sus datos personalesa, el programa tambien ayuda a verificar el correo electronico del usuario para confirmar datos y que sea cuenta de el usuario

- En general el proyecto funciona con autenticacion de cuenta y asegurando que solo usuarios registrados y validos puedan entrar a la aplicacion
